# HuntersNotebook

A free, easy to learn and navigate system to help you store and calculate builds for (at this moment) __MonsterHunterWilds__ without any unnecessary bloat or imagery that can lead you away from the main focus.
- This mainly focuses on armor sets/builds in a format that is as (if not more) user friendly as the game, as everything you need will be on your screen at all the time to avoid scrolling up and down. On top of this, I will make sure to translate all the stupid vauge stats such as "slightly increase" to numbers you can actually deal with.
- In order to appeal to collecting all the information in one place, I will also provide an overly detailed overview of all the monsters in the game passed that of what the game offers. On the same note I will also include the location of all recources needed to crafting material (only) which the Wiki has failed to do, they don't have all the information.
